# 语法翻译训练 2026-08-03

## 1. 时态-现在完成时不搭配过去时间点

🀄 这个 bug 昨天已经被修复了，但今天早上又出现了。

✅ This bug was fixed yesterday, but it has appeared again this morning.

> 语法：yesterday 是封闭的过去时间戳，必须用一般过去时 was fixed；不能用 has been fixed yesterday

⚠️ 用户原句：This bug has been fixed yesterday, but It has appeared this morning.
错误原因：现在完成时不能与具体过去时间点（yesterday）连用；后半句缺少 again

---

## 2. 时态-持续状态用现在完成时

🀄 我来这家公司已经快三年了。

✅ I have been with this company for almost three years.

> 语法：持续到现在的状态用现在完成时 have been；表示持续时间段必须加 for；不用 came（过去时表已结束）

⚠️ 用户原句：I came to this company almost three years.
错误原因：came 是一般过去时（已结束动作），缺少 for，应为 have been with ... for almost three years

---

## 3. 五成分-SVOC（call + 宾语 + 宾补）

🀄 我们把这个新功能叫做「一键部署」。

✅ We call this new feature "One-Click Deployment."

> 语法：SVOC 结构，call + O + C，宾补直接跟在宾语后，不加连词

⚠️ 用户原句：we call this new feature "one key to deployment"
错误原因：句子结构正确，"one key to deployment" 词汇不自然；"一键"英文标准说法是 one-click（加连字符），to 多余

---

## 4. 定语从句-who 引导人物定语从句

🀄 那个写了核心支付模块的工程师上周突然离职了。

✅ The engineer who wrote the core payment module suddenly resigned last week.

> 语法：定语从句放被修饰词右边（右六思维），who 引导人物定语从句，陈述语序；last week 是具体过去时间点，用一般过去时

---

## 5. 名词从句-whether 引导宾语从句

🀄 我不确定这个版本今天能不能按时发布。

✅ I'm not sure whether this version can be released on time today.

> 语法：whether 引导宾语从句，从句内保持陈述语序；version 是被发布对象，用被动 be released；副词语序 on time（方式）在 today（时间）前

⚠️ 用户原句：I'm not sure whether this version can publish today on time.
错误原因：version 不能主动 publish，应用被动 be released；today on time 语序颠倒，应为 on time today；技术场景用 release/ship 不用 publish

---

## 6. 状语从句-since 引导原因（让步推进）

🀄 既然大家对这个方案都没有异议，我们就按这个来推进吧。

✅ Since everyone has no objections to this proposal, let's move forward with it.

> 语法：since 句首引导"既知事实"原因从句，后半句用 let's 表号召；objection to（固定搭配）；"按这个推进" = move forward with it

⚠️ 用户原句：Since we don't have objection for this solution, we will carry out following it.
错误原因：objection 可数不能裸奔，介词应为 to 不是 for；carry out following it 不自然，应为 move forward with it；let's 比 we will 更自然

---

## 7. 非谓语-to do 表目的状语

🀄 为了在下班前完成部署，我跳过了午饭。

✅ In order to finish the deployment before leaving work, I skipped lunch.

> 语法：in order to do 表目的，放句首加逗号；before leaving work 用动名词；skipped（双写 p）

⚠️ 用户原句：in order to finish the deployment before leaving work, I skiped lunch.
错误原因：拼写错误，skiped → skipped（短元音+单辅音结尾需双写）

---

## 8. 虚拟语气-与过去事实相反

🀄 如果昨天我参加了那个架构评审，就不会漏掉这个关键需求了。

✅ If I had participated in that architecture review yesterday, I wouldn't have missed the critical requirement.

> 语法：过去虚拟——条件句用过去完成时 had done，结果句用 would have done；时态后退标记反事实

⚠️ 用户原句：If I parcitipated in that architecture review yesterday, I didn't miss the critical requirement.
错误原因：条件句应为 had participated（过去完成），结果句应为 wouldn't have missed（would have done）；拼写 parcitipated → participated

---

## 9. 虚拟语气-与过去事实相反（同结构换场景）

🀄 如果我们当时用了缓存，服务就不会崩了。

✅ If we had used cache at that time, the server wouldn't have crashed.

> 语法：过去虚拟公式：If + had done → would have done；wouldn't 后接动词原形 have，不接 has

⚠️ 用户原句：If we have used cache at that time, the server wouldn't has crashed.
错误原因：条件句 have used → had used（现在完成≠过去完成）；wouldn't has → wouldn't have（情态动词后只接原形）

---

## 10. 情态动词-must 推测当下状态

🀄 他今天没来站会，肯定是被什么事情卡住了。

✅ He didn't show up for the standup today. He must be stuck in something.

> 语法：must + 动词原形表强推测；"被卡住"是状态用 be stuck；stuck 是过去分词本身，无需加 -ed

⚠️ 用户原句：He didn't join the stand-up meeting today, he must stucked in something.
错误原因：must 后只能跟原形，应为 must be stuck；stucked 不存在，stuck 已是过去分词；两句不能只用逗号连接（comma splice）

---

## 11. 状语从句-时间（主将从现）

🀄 一旦 CI 跑完，你就通知 QA 开始测试。

✅ Once CI finishes, notify QA to start testing.

> 语法：时间从句（once/when/after）表将来时从句用现在时（finishes），不用 will；QA 作职能不加 the；start testing 用动名词

⚠️ 用户原句：Once CI running finish, you can notify the QA to start the test.
错误原因：running finish 不构成完整谓语，应为 finishes（第三人称单数）；时间从句不加 will；the QA → QA；start the test → start testing

---

## 12. 情态动词-should have done（过去遗憾/批评）

🀄 你应该在提 PR 之前先让我帮你看一下代码的。

✅ You should have let me review your code before you submitted the PR.

> 语法：should have done 表"过去本该做却没做"的遗憾或批评；should do 是将来建议，两者语气不同；PR 前需要冠词，从句用过去时

⚠️ 用户原句：You should let me review your code before you create PR.
错误原因：should let（将来建议）应为 should have let（过去遗憾）；create PR → submitted the PR（加冠词，用过去时）

---

## 13. 名词从句-疑问词引导宾语从句（陈述语序）

🀄 你知道那个新来的前端工程师之前在哪家公司工作吗？

✅ Do you know which company the new frontend engineer worked at before?

> 语法：疑问词引导宾语从句必须恢复陈述语序，去掉助动词 does/did，直接用主语+动词；在公司工作用 work at/for，不用 work in

⚠️ 用户原句：Do you know where does the new frontend engineer worked in before?
错误原因：疑问从句不倒装，应为 where he worked（去掉 does）；worked in → worked at；does...worked 双重谓语错误

---

## 14. 时态-现在完成进行时（have been doing）

🀄 我们已经连续优化这个接口的性能三周了，但响应时间还是没有明显改善。

✅ We have been optimizing the performance of this API for three weeks, but the response time has not improved significantly.

> 语法：have been doing 表从过去持续到现在的动作；持续时间用 for；response time 固定搭配；has not improved significantly（动词谓语）

⚠️ 用户原句：We have been optimzed the performance of the API about three weeks, but the responsing time has not obvious improvement.
错误原因：have been + doing（非 done）；about → for（持续时间）；responsing → response（固定搭配）；has not obvious improvement 语法不成立，改为 has not improved significantly

---

## 15. 非谓语-done 作定语 + 定语从句

🀄 被回滚的那个版本里有一个隐藏的 bug，导致了这次线上故障。

✅ The release that was rolled back had a hidden bug that caused this production outage.

> 语法：done 作定语可前置（rolled-back release）或用关系从句（that was rolled back）；bug 后用 that 引导定语从句；production outage = 线上故障

⚠️ 用户原句：The release that has been rolled back has a hidden bug led to this online malfunctioning
错误原因：led to 悬空，需加 that 成为定语从句；online malfunctioning 不自然，应为 production outage；时态统一用过去时
