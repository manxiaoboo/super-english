## Chinese Intention

告诉对方等完成A任务后就开始B任务

## Natural Chunk

Once I finish [task], I'll start [next action]

## Avoid Saying

- After I done X, I'm going to do Y

## Sentence Patterns

- Once I finish the [analysis/review/deployment], I'll start [merging/testing/...].
- Once I'm done with X, I'll move on to Y.

## Real-Life Examples

- Once I finish the memory leak analysis, I'll start merging the version 3 code.
- Once I finish the code review, I'll start working on the deployment script.

## Usage Notes

once 引导时间从句用现在时表将来（主将从现）；比 after 更强调'一完成就立刻'的紧接感

## Production Prompts

告诉同事：等我做完这个PR review，就去处理那个线上告警
